================================================================
  V4 大樓住戶管理 - 使用說明
================================================================

【一鍵啟動】
  雙擊「啟動 V4 住戶管理.bat」即可開啟應用程式
  （使用 Edge 瀏覽器 App 模式，沒有網址列，看起來像原生 App）


【系統需求】
  - Windows 10 / Windows 11（已內建 Edge 瀏覽器）
  - 顯示器建議 1366×768 以上
  - 不需要網路，全部資料都存在你的電腦上


【資料儲存位置】
  所有資料儲存在 Edge 瀏覽器的「IndexedDB」內，位置：
    C:\Users\<你的帳號>\AppData\Local\Microsoft\Edge\User Data\Default\IndexedDB\

  簡單說：存在你電腦的 Edge 裡面，跟書籤、密碼一樣安全。
  解除安裝 Edge 或清除瀏覽器資料 = 資料會消失，請定期備份。


【如何備份】
  1. 開啟 V4 大樓住戶管理
  2. 進入「備份」模組（首頁選單）
  3. 選擇匯出格式：
     - .db      ：完整 SQLite 資料庫（二進位，最完整）
     - .json    ：JSON 格式（人類可讀，方便檢視）
     - .json.gz ：壓縮 JSON（檔案最小）
  4. 存到隨身碟、雲端硬碟、或另一顆硬碟

  建議：每週備份一次，存到「自己電腦以外」的地方。


【如何還原備份】
  1. 開啟 V4 大樓住戶管理
  2. 進入「備份」模組
  3. 選擇「匯入備份」
  4. 選擇之前匯出的檔案
  5. 確認後資料就會回來


【如何更新版本】
  1. 先備份目前資料（用「備份」模組匯出 .db）
  2. 把舊的 dist 資料夾整個刪除
  3. 把新版的 dist 資料夾放到原本的位置
  4. 雙擊「啟動 V4 住戶管理.bat」
  5. 進入「備份」模組 → 匯入剛才備份的 .db
  6. 完成


【資料不見了怎麼辦？】
  症狀：開啟後畫面空白、或資料全部消失
  可能原因：
    1. Edge 更新後清除了 IndexedDB（罕見）
    2. 你用 Chrome/Firefox 開啟了（資料在 Edge，不在其他瀏覽器）
    3. Edge 用「無痕模式」開啟（無痕模式不會保留 IndexedDB）
    4. 電腦重灌 Edge 被移除

  處理方式：
    1. 確認是用「啟動 V4 大樓住戶管理.bat」開啟（不是手動開 Edge）
    2. 確認 Edge 不是無痕模式
    3. 從備份檔還原

【常見問題】

  Q: 可以離線使用嗎？
  A: 可以。完全不需要網路，整個 App 都在你的電腦裡。

  Q: 資料會上傳到雲端嗎？
  A: 不會。所有資料都在你的電腦上，沒有任何上傳行為。

  Q: 可以多人共用嗎？
  A: 不行。每台電腦的 Edge 是分開的，資料不互通。
     如需多人共用，請改用「伺服器版」（需另安裝後端）。

  Q: 怎麼換到新電腦？
  A: 把整個 dist 資料夾複製到新電腦，
     並用「備份」模組匯出 .db 再匯入新電腦的 V4。

  Q: Edge 佔記憶體怎麼辦？
  A: V4 用 Edge 開啟約 150-300MB 記憶體。
     若電腦老舊，建議關閉其他分頁後再開啟 V4。

  Q: 可以改用 Chrome 嗎？
  A: 可以，但資料會存在 Chrome 的 IndexedDB，跟 Edge 分開。
     若想全部統一用 Chrome，請修改啟動檔把 msedge.exe 換成 chrome.exe。
